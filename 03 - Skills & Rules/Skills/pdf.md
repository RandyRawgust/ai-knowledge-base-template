# pdf — PDF Processor

Read, extract, create, merge, split, fill forms, OCR. Triggered by mentions
of PDF, .pdf, form, extract, merge, split.

## Capabilities

- Extract text and tables from PDFs
- Create new PDFs from content
- Merge multiple PDFs into one
- Split PDFs into separate files
- Rotate pages, add watermarks
- Fill PDF forms
- Encrypt / decrypt
- OCR scanned PDFs to make searchable

## Used by

- [[Career]] (resumes, job apps, pay stubs all live as PDFs)
- [[KSP RPG]] (rulebook PDF output)
- Any project producing or consuming PDF artifacts
