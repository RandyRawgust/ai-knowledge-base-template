# pptx — PowerPoint Handler

Slide deck creation, parsing, editing, combining. Triggered by "deck",
"slides", "presentation", or any `.pptx` filename.

## Capabilities

- Create slide decks / pitch decks from scratch
- Parse and extract text from existing decks
- Edit / update existing presentations
- Combine or split slide files
- Templates, layouts, speaker notes, comments

## Used by

- [[02 - Projects/Misc/Education]] — slide content for courses (when needed)
- One-off pitch decks
