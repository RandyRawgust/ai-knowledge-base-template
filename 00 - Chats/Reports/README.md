# Project Reports

Markdown reports generated by the `/report` skill (voice-report mode of the [[../../03 - Skills & Rules/Agents/Specialists/presenter|presenter specialist]]).

Each report has a sibling HTML deck in `20 - Decks/` with matching date. The MD is the text-of-record, vault-linked. The HTML is the visual companion that renders live during the voice walkthrough.

## File naming

`<YYYY-MM-DD>-<project-slug>-report.md`

Examples:
- `2026-05-20-terrawatt-report.md`
- `2026-06-01-ksp-series-report.md`
