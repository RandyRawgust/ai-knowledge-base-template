# Decks

Live HTML presentations created by [[03 - Skills & Rules/Agents/Specialists/presenter|Presenter]] during voice chats.

## How it works

1. In a Claude voice chat (mobile or web), say **"call presenter"**
2. Presenter creates a new file here: `<YYYY-MM-DD HHmm> <slug>.html`
3. As you talk, sections get appended to the file with bullets, diagrams, code, etc.
4. Open the file in your browser (or refresh if already open) to follow along
5. Say **"presenter, stop"** to close the deck

See [[04 - Templates/Presenter Deck Template]] for the format.
