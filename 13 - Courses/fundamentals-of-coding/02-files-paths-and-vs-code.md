# 02 — Files, paths, and a real text editor (VS Code)

## What you'll learn

- The difference between **absolute** and **relative** paths — and why mixing them up causes most beginner bugs
- What's actually inside a file (plain text vs binary) and why code is always plain text
- How to install **VS Code** and verify it from PowerShell with `code --version`
- The three-panel layout: Explorer, Editor, Terminal
- Why you open *folders*, not files
- Editing, saving, and the unsaved-changes dot
- Using the integrated terminal inside VS Code
- The `code .` bridge command — your daily PowerShell → editor handoff
