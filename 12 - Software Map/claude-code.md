# Claude Code

Terminal-based Claude — a command-line AI agent for coding, file operations,
and repo work. Same model family as [[cowork]] but lives in the shell.

## Touches

- Any project directory you cd into
- [E:\Projects](file:///E:/Projects) — primarily

## Powers / Used by

- Direct repo work (TerraWatt, KSP RPG, etc.) when projects need code-heavy
  assistance
- Karpathy LLM-wiki maintenance — point it at the vault, ask it to compile
  topic notes from `11 - Sources/`

## Related software

- [[cowork]] — desktop / GUI sibling
- [[git]] — frequent collaborator

## Notes

- Best for: long-form coding sessions, repo-wide refactors, vault maintenance
- Slash commands available (review, security-review, etc.)
- Plugins/skills install separately from Cowork's
