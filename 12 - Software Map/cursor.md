# Cursor

VS Code fork with built-in AI assistance. The IDE you reach for when you're
actively writing/editing code with AI in the loop. Backend: Claude / GPT-5 /
others, switchable.

Different category from [[cowork]] (chat) or [[claude-code]] (terminal) —
this is the *editor*. Open it when you're sitting down to *write* code, not
when you're delegating a task.

## Touches

- Any project directory you open as a workspace
- [F:\Cursor Workspaces](file:///F:/Cursor%20Workspaces) — Cursor's per-workspace state cache (locked while running)
- [F:\Game Dev\Projects](file:///F:/Game%20Dev/Projects) — game dev work
- [E:\Projects](file:///E:/Projects) — non-game dev work

## Powers / Used by

- [[02 - Projects/Game Dev/TerraWatt]], [[Godot Projects]], [[Citizen RED-6]] — actively edited here
- Vault notes occasionally (open the AI Knowledge Base folder as a workspace
  for deep editing sessions)

## Notes

- Cursor Workspaces folder on F: is locked while Cursor is running. To clean
  up: close Cursor entirely, then delete or change Cursor's storage path in
  Settings.
- Composer mode is closest to "agent" behavior; chat mode is closer to a
  pair programmer
