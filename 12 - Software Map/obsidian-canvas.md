# Obsidian Canvas

Built-in Obsidian feature — infinite whiteboard where you drag notes, images,
PDFs, and free-form cards onto a 2D surface. Brainstorming, mind-mapping,
visual planning. Saves as `.canvas` files (JSON).

## Touches

- [E:\Projects\AI Knowledge Base](file:///E:/Projects/AI%20Knowledge%20Base) — canvases live in the vault
- Any vault notes you embed onto a canvas

## Powers / Used by

- Project planning (each project can have a `<project>.canvas` for visual
  thinking)
- Software-to-files map visualization (alternative to graph view — manual
  layout instead of auto)

## Related software

- [[obsidian]] — host
- Excalidraw plugin — for hand-drawn elements inside canvases

## Notes

- Right-click vault sidebar → New canvas
- Drag notes from the file explorer onto the canvas to embed them
- Canvas embeds are *live* — edits sync to the underlying note
- Don't use canvas as a *replacement* for note-taking; use it as a planning
  layer that points at your real notes
