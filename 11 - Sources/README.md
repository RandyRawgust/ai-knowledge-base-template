# Sources

Raw material the LLM compiles topic notes from. Not for human reading
necessarily — for ingestion.

## What goes here

- Articles clipped via **Obsidian Web Clipper** browser extension
- PDFs you want to reference but not yet structure
- Conversation transcripts (full text, before they're summarized into `00 - Chats/`)
- Code samples, snippets
- YouTube transcripts (use the Web Clipper or paste manually)

## Naming

- Web Clipper handles its own naming; let it
- Manual additions: `<YYYY-MM-DD>_<short-slug>.md` or `.pdf`

## Workflow

1. You drop sources here over time (clip during browsing, paste during research)
2. When a theme accumulates, ask Claude:
   *"Compile a topic note from these sources: [list paths]"*
3. Claude writes the topic note into `10 - Topics/`, links it back here

## Cleanup

Sources can stay forever — they're cheap. But if a source has been fully
absorbed into a topic note and you'll never reread it, move to
`G:\Archive\Sources` to keep the vault snappy.
